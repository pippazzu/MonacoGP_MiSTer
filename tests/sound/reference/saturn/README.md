# Saturn remake recordings (reference only, unconfirmed)

Sound files from the Sega Saturn remake of Monaco GP, supplied by Aldo
(6 November 2026). They are not recordings of an original board.

- `6CAR1.WAV` (0.96 s) and `6CAR2.WAV` (1.13 s): other cars passing.
  Stereo, 44.1 kHz, 16-bit.

Aldo finds the remake accurate for the other sounds, but these two are
unconfirmed. Most surviving boards produce only one passing/other-car sound,
which suggests those boards are faulty rather than that the remake is wrong.

Use them as a comparison when tuning the other-car sound (sound sheets D-6
and D-7), never as evidence that overrides the schematic. Private
repository only.

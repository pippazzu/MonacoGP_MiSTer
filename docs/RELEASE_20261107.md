# Monaco GP / Pro Monaco GP, 7 November 2026

This release adds Pro Monaco GP using the same RBF and original Monaco GP ROM set. It includes Pro scoring/rank changes, display/attract circuitry, reconstructed +200 and lamp PROMs, and both MRAs. The other-car sound comparison adds build-time R109 options; the default remains the schematic's 330 ohms.

## Validation

The Pro MRA branch completed the Icarus simulation suite, including normal play, play with sound and Pro bonus payout. Its four Verilator sound cases were run separately and passed. The final combination additionally passed game, attract, three panel cases and the sound check. The full suite was not rerun on the final combined tree.

Quartus seed 2 completed with positive timing slack: setup +0.502 ns, hold +0.107 ns, recovery +4.118 ns, removal +1.348 ns, minimum pulse width +0.529 ns. RAM and DSP resources are fully used.

The owner confirmed operation on MiSTer, including crash clearing the car bar while retaining bonuses, Pro NVRAM and the RAM reset DIP. A dedicated game-level crash/lamp regression bench remains to be added. Original Monaco GP first-boot scrolling and off-road clearing of the Pro car bar remain unresolved.

For the public export, Python ROM/MRA tests and the source manifest are checked again. No original ROM data or service-manual scans are included.
